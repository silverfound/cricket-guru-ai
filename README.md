# Cricket Guru AI

Separate starter website for international ODI, T20I and major T20 franchise match analysis.

## Current status
This is a starter UI/demo, not a live prediction service. No cricket data API or trained historical model is connected yet. It intentionally does not invent a winner or score.

## Next stages
1. Publish from a separate repository and free static host.
2. Verify a cricket data provider's competition coverage, usage limits and licensing.
3. Build separate ODI, T20I and franchise-T20 statistical models and backtest historical predictions.
4. Add traditional Urdu/Arabic Abjad mappings and optional numerology/astrology-inspired symbolic analysis, clearly separated from statistical predictions.
5. Add prediction history and accuracy tracking.

## GitHub Pages
Repository Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.

Never put API secrets in public browser JavaScript or public GitHub files. Use a server-side function if a provider requires a secret. Free data coverage varies by competition. Abjad, numerology and astrology are not scientifically validated cricket prediction methods.
